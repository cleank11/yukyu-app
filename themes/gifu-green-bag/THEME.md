# Gifu Green Bag

A4縦のお知らせポスター用テーマです。アパート共用部への掲示と、家庭用プリンターでの印刷を前提にしています。
雰囲気は「わかりやすい・明るい・やわらかいイラスト系」です。注意書きでも、読む人を責める感じにしません。

| ファイル | 中身 |
|---|---|
| `theme.css` | カラー・フォント・サイズのトークンと共通部品（帯・バッジ・カード・価格・注意語・線画モチーフ） |
| `poster-sample.html` | 見本ポスター（燃えるごみ・指定袋のおしらせ）。`○` と `000` を書きかえて使う |
| `poster-sample.pdf` | 見本をA4で書き出したもの（フォント埋め込み済み） |
| `poster-sample.png` | プレビュー画像 |
| `bag-photo.png` | 実物の指定袋（45L）の写真をAI超解像（EDSR・4倍）で 924×1396px にしたもの。見本の上段で使用 |
| `bag-photo-original.png` | 元の写真（231×349px） |

## カラーパレット

| 名前 | HEX | 使う場所 | 使わない場所 |
|---|---|---|---|
| ふくろグリーン | `#1DBF62` | 袋のイラスト、アイコン、飾り線、線画モチーフ | **文字の背景**、文字色 |
| ふかみグリーン | `#0B7A3E` | 白文字をのせる見出しの帯、小見出しの文字 | — |
| おしらせイエロー | `#FFD23F` | 日付バッジ、イエローカード、マーカー強調 | 白文字の背景 |
| すみ紺 | `#1F2A44` | 本文、黄色の上の文字、黄色の面の縁取り | — |
| 半透明ホワイト | `#F6FBF7` | ページの背景 | — |
| わかばグリーン | `#E3F7EA` | 表やカードの下敷き | — |
| やさしいレッド | `#E4572E` | 「回収されません」の**一語だけ** | ほかのすべて |

### 組み合わせのルール

- **白文字は `#0B7A3E` の上だけ**に使います（コントラスト比 約5.4:1）。
- **黄色の上の文字はすみ紺**にします（約9.9:1）。
- `#1DBF62` は背景と比べてコントラストが低い（約2.3:1）ため、文字にも文字の背景にも使いません。イラストと線にだけ使います。
- `#E4572E` は背景とのコントラストが約3.5:1です。**24pt以上の太字**で使い、色以外の手がかりも必ず添えます（下記参照）。

## フォント

| 用途 | フォント | ウェイト |
|---|---|---|
| 見出し・バッジ・価格の数字 | M PLUS Rounded 1c | ExtraBold (800) |
| 本文 | BIZ UDPGothic | Regular (400) / Bold (700) |

どちらも Google Fonts から読み込みます（`theme.css` 冒頭の `@import`）。

## 文字サイズ

| 要素 | サイズ | 備考 |
|---|---|---|
| 大見出し（帯の中） | 36〜44pt | 1行あたり12字くらいまで |
| 小見出し | 24pt | ふかみグリーン＋点線の飾り線 |
| リード文 | 20pt | Bold |
| 本文 | **16pt以上** | これより小さくしない（注記・連絡先も同じ） |
| 価格の数字 | **36pt以上**（見本は40pt） | 「円」は20pt |

## かたち

- 角丸（大 6mm／中 4mm／バッジはピル型）、**影なし**、フラット塗り。
- 黄色の面（バッジ・イエローカード）には **0.5mm のすみ紺の縁取り**をつけます。白黒コピーで黄色が薄いグレーになっても、枠が残るようにするためです。
- 区切りは `#1DBF62` の点線か実線（0.6mm）を使います。

## モチーフ

実物の指定袋のデザインに合わせて、次の3つを `#1DBF62` の細い線画（線幅0.6mm相当・塗りなし・角丸）で描きます。

- **花火**：放射線＋中心の小円＋外側の点
- **岐阜城と山**：なだらかな山の稜線＋頂上の天守（屋根2層）
- **鵜飼の舟**：細長い舟＋鵜匠＋かがり火＋波線

本文にかからない余白（リード文の横や、フッターの上の帯）に**小さく散らします**。主役にはしません。

## 袋の写真

- 実物の袋の写真（`bag-photo.png`）は、上段の「この緑のふくろ」の横に置き、どの袋を使えばよいかが一目でわかるようにします。白い背景はそのまま残し、角丸の白いカードとして見せます。
- 元の写真は 231×349px と小さいため、AI超解像（OpenCV の EDSR モデル・4倍）で 924×1396px に拡大し、軽くシャープをかけています。幅30mmなら約780dpiで、輪郭はくっきり出ます。
- ただし超解像は、もとの写真に写っていない細部までは作れません。袋のいちばん小さい注意書きは読めないままです。60mm以上の大きさで載せたいときは、実物を撮りなおした写真に差しかえてください。
- 写真には45Lと書いてあるため、大・中・小の値段カードには写真を使わず、線画の袋アイコンを大きさ違いで使います。

## 色だけに頼らない（白黒コピー対策）

| 伝えたいこと | 色 | 色以外の手がかり |
|---|---|---|
| 出してはいけない | やさしいレッド | ✕のアイコン、太字24pt、下線 |
| 日付・期限 | イエロー | ピル型バッジの形、縁取り、カレンダーのアイコン |
| 場所 | わかばグリーン | ピンのアイコン |
| 指定袋 | ふくろグリーン | 袋のイラスト、「緑の指定袋」と文字で明記 |

見本は、グレースケールにしても読めることを確認しています。

## ことば

- 「〜してください」「〜しましょう」「いっしょに」を使い、禁止形（「〜するな」「厳禁」）は使いません。
- 注意のあとには理由をひと言添えます（例：「置いたままになると、みんなの場所がよごれてしまいます」）。
- ひらがなを多めにして、漢字はよく使うものだけにします。

## 印刷のヒント

- PDFは用紙A4・余白なし（`@page { margin: 0 }`）で作っています。フチなし印刷に対応していないプリンターでは、端の数mmが切れることがあります。重要な内容は外周から9mm以上内側に置いています。
- インクを節約したいときは、`body` と `.page` の背景 `--ggb-paper` を `#FFFFFF` にしても、見た目はほとんど変わりません。
- ブラウザから印刷するときは「背景のグラフィック」をオンにしてください。
